### Smart Sourcing Assistant (C++)

A C++ command-line tool built by a first-year student to estimate real-time profit margins for e-commerce resellers. Uses fundamental C++ (vectors, loops, conditional logic) to calculate net profit after platform fees. 

### 🛠️ What I am Building & Learning:

* **Fast Price Inputs:** A logic system that simulates rapid-tap buttons (+1, +5, +10) to log costs quickly without typing out full numbers.
* **Platform Fee Calculator:** Simple conditional logic to automatically subtract real fees from platforms like eBay, Etsy, and Facebook Marketplace.
* **Negotiation Check:** An algorithm that helps decide if an item is worth buying if the seller is willing to lower the price.

### 🚀 Technical Focus (My First Semester Goals):

I am using this project to practice fundamental C++ concepts outside of my classes: 

* Variables, loops, and conditional statements (if/else).
* Using std::vector to store data in memory.
* Writing clean, readable code and managing my daily progress using Git.
